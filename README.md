# 协作道场：AI知行合一团队协作流

> 定位：AI与人类的"共修"平台

---

## 📖 项目简介

本仓库定义一套标准化的协作SOP，将心学融入工程化实践。

**核心理念：**
- 边做边思 - 在协作中思考
- 知行合一 - 理论与实践统一
- 共同进步 - AI与人类共同修行

## 🏗️ 项目结构

```
ai-team-xinzhi-workflow/
├── workflows/
│   ├── pr_review/      # PR审查流程
│   ├── progress_report/ # 进度报告
│   └── code_review/    # 代码审查
├── scripts/            # 协作脚本
├── tests/              # 测试套件
├── examples/           # 使用示例
├── docs/               # 文档
├── config/             # 配置文件
└── .github/workflows/  # CI/CD
```

## 🎯 核心功能

### 1. 标准化流程
- PR审查流程
- 进度汇报模板
- 代码审查清单

### 2. 智能协作
- 自动进度跟踪
- 智能提醒机制
- 协作建议生成

### 3. 反思改进
- 协作复盘
- 流程优化
- 经验总结

## 🚀 快速开始

```bash
# 创建PR
python scripts/create_pr.py --title "新功能" --body "描述"

# 生成进度报告
python scripts/progress_report.py --week 30

# 代码审查
python scripts/code_review.py --pr 123
```
